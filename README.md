# Finance Jarvis

한국투자증권(KIS) OpenAPI로 국내 주식·ETF를 자동매매하고, 글로벌 시장 인사이트와 미국장 시그널까지 통합 관제하는 개인 퀀트 프로젝트다. 크게 다섯 부분으로 되어 있다.

- **자동매매 엔진**: 30분마다 등록한 종목을 돌면서 매수/매도를 판단한다. 일봉 지표(추세 레짐 포함), 30분봉, 뉴스 감성(3계층 ETF 라우팅), (선택) 밸류에이션을 합친 시그널을 쓰고, 손절(-6%)과 추세 연동 트레일링 분할 익절(Scale-Out)은 언제나 먼저 본다.
- **AI 포트폴리오 에이전트 & 해외 프록시 매매**: 코스피·코스닥 전 종목과 해외 유망 종목·매크로 자산을 발굴해 국내 상장 대체 ETF로 매핑(Proxy Trading)하고, Gemini가 매크로 로테이션과 비중 조정을 제안한다. 수동 승인 또는 가드레일 통과 시 자율 반영(Auto-Apply)을 선택할 수 있다.
- **매매 복기 · 백테스팅 · 배당 대시보드**: 쌓인 체결·판단 기록으로 손익과 의사결정을 복기하고, 배당·분배금(Total Return) 추적 및 S&P 500 ETF 벤치마크 대비 전략 백테스팅을 수행한다.
- **AI 인사이트 묶음 분석**: 매일 정기 스케줄(09·12·15·21시 KST)로 증권사 리포트 본문, 뉴스 헤드라인, 보유종목 감성, 발굴 결과를 묶음(batch) 단위로 수집·요약한다.
- **미국장 시그널 룸 & 멀티 계좌 마스터 허브**: 해외 직투 계좌를 위해 미국장 종목을 30분 주기로 모니터링해 텔레그램 푸시 알림을 보내고, 여러 계좌 프로필(ISA·실전·모의)을 마스터 허브에서 한눈에 관제한다.

기본값은 모의투자, 국내 전용이다. 실거래는 설정을 두 군데 바꿔야 켜진다.

## 빠른 시작

필요한 것:

- Python 3.12 이상, [uv](https://docs.astral.sh/uv/)
- KIS OpenAPI 앱키와 시크릿. 모의투자는 계좌가 모의투자 주문서비스에 신청되어 있어야 한다.
- KIS HTS ID (체결통보 웹소켓에 필요)
- Gemini API 키 (선택). 없으면 뉴스 감성, AI 인사이트, 포트폴리오 제안이 꺼지고 기술적 지표만 쓴다.
- 텔레그램 봇 토큰 및 채팅 ID (선택). 있으면 강한 매매 시그널(60% 이상) 및 손절/익절, 미국장 알림을 모바일로 받는다.

설치:

```bash
uv sync
cp .env.template .env
```

`.env` (또는 멀티 프로필 사용 시 `.env.isa`, `.env.real`, `.env.mock`)에는 최소한 아래를 채운다.

```dotenv
KIS_APP_KEY=...
KIS_APP_SECRET=...
KIS_ACCOUNT_NO="12345678-01"
KIS_HTS_ID=...
IS_MOCK=True
GEMINI_API_KEY=...        # 선택
TELEGRAM_BOT_TOKEN=...    # 선택
TELEGRAM_CHAT_ID=...      # 선택
```

손절 폭, 주문 한도, 발굴 가중치 같은 나머지 설정은 [core/config.py](core/config.py)에 기본값이 정의되어 있다.

### 실행 방법

**1) 단일 계좌 직접 실행 (개발/테스트)**

터미널 두 개로 실행한다.

```bash
# 1. API 서버 (엔진이 실제로 도는 곳)
uv run uvicorn api.main:app --port 8800

# 2. 대시보드
uv run streamlit run app.py --server.port 8501
```

**2) 백그라운드 데몬 스크립트 (`scripts/service.sh`)**

터미널을 닫아도 24/7 돌아가도록 `nohup`으로 API(:8800)와 UI(:8501)를 띄우고 엔진과 스케줄러까지 자동 기동한다.

```bash
./scripts/service.sh start    # 기동 (stop / restart / status / logs 지원)
```

**3) 멀티 계좌 프로필 관리 (`scripts/manage_profile.py`)**

ISA 절세 계좌(`isa`, :8800/:8501), 실전 일반 계좌(`real`, :8801/:8502), 모의투자 계좌(`mock`, :8802/:8503)를 각각 독립된 DB와 `tmux` 세션으로 동시에 운영할 수 있다.

```bash
uv run python scripts/manage_profile.py list        # 프로필 목록 및 포트·상태 확인
uv run python scripts/manage_profile.py start-all   # 모든 프로필 일괄 기동
uv run python scripts/manage_profile.py master      # 통합 관제용 마스터 허브(:8500) 기동
```

테스트는 `uv run pytest`, CLI 백테스팅은 `uv run python scripts/run_backtest.py`로 실행한다.

실전투자로 바꾸려면 `IS_MOCK=False`만으로는 안 되고 `I_UNDERSTAND_REAL_MONEY_RISK=true`도 같이 있어야 한다. 하나만 바꿔서 실수로 실거래가 시작되는 걸 막으려는 장치다.

## 페이지

좌측 사이드바 메뉴에 다섯 페이지가 있다.

### 🏢 계좌 마스터 허브 (`pages/0_계좌_마스터.py`)

등록된 모든 계좌 프로필(`isa`, `real`, `mock`)의 프로세스 상태(API·UI·엔진·킬스위치), 총자산·예수금·수익률을 한 화면에서 모아 보고, 원클릭으로 개별 계좌 기동/정지/재시작 및 활성 프로필 전환을 제어한다. `:8500` 포트로 띄우면 이 페이지가 기본 홈이 된다.

### 📈 매매 복기·분석 (`dashboard.py`)

읽기 전용이다. 체결(`fills`), 판단(`decision_log`), 리밸런싱, 배당 기록으로 성과를 계산해서 보여주기만 하고 매매에는 관여하지 않는다. 사이드바에서 분석 기간(7~90일)과 색상 방식(한국식은 상승이 빨강)을 고를 수 있다.

- **성과 오버뷰**: 종목별 누적손익과 수익률, 일별 평가손익, 누적수익률(배당 포함 Total Return 비교)과 낙폭, 종목×날짜 히트맵.
- **매매 달력**: 월 달력에 일별 실현손익과 체결 건수를 표시한다. 날짜를 고르면 체결 내역이 나온다.
- **의사결정 복기**: 가격 차트에 엔진의 매수/매도/관망 판단을 찍는다. 판단을 선택하면 당시 시그널과 뉴스·밸류에이션 근거, 손절 판정 같은 원본 기록을 펼쳐 볼 수 있다.
- **리밸런싱 이력**: 리밸런싱 이벤트 목록, 목표 비중 변화, 승인 이후 성과를 이전 포트폴리오와 비교한다.
- **전략 백테스팅**: 보유·관심 종목에 현재 엔진의 스윙+추세 레짐+분할 익절 로직을 시뮬레이션하고, 수수료·거래세·슬리피지를 반영한 누적 수익률과 알파(α)를 벤치마크(`360750` TIGER 미국S&P500 등)와 비교한다.
- **배당·분배금**: ETF 분배금과 주식 배당금을 기록·관리하고, 시세 차익에 배당을 더한 총수익(Total Return)을 계산한다.

### 🤖 KIS 자동매매 (`pages/1_KIS_자동매매.py`)

엔진을 켜고 끄고, 포트폴리오와 AI 제안을 관리하는 페이지다.

- **개요**: 엔진 상태(하트비트, 체결통보 웹소켓, 킬스위치)와 시작/정지/긴급정지 버튼, 보유 종목 비중 도넛차트.
- **설정 · 리스크**: 지금 적용 중인 설정값을 보여준다. 해외 종목의 국내 ETF 대리 매매(Proxy Trading)나 적립식(ISA/DCA) 모드 토글도 지원한다.
- **포트폴리오 · 비중**: 종목 등록/삭제, 목표 비중 입력, 현재 포지션. 삭제한 종목은 바로 팔지 않고 정리 대기 상태가 된다.
- **AI 에이전트**: 리밸런싱 제안 요청과 승인/거부, 스케줄러 및 무승인 자율 반영(Auto-Apply) on/off, 종목 발굴 후보와 오늘의 발굴 결과, 보유 종목의 샤프·소티노·베타·MDD 지표를 볼 수 있다.
- **매매 로그**: 최근 판단 이력. 종목과 액션(BUY/SELL/NO_OP)으로 거를 수 있고, 손절·트레일링·스윙·온보딩 같은 사유가 뱃지로 붙는다.

### 💡 AI 인사이트 (`pages/2_인사이트.py`)

하루 4회(09:00, 12:00, 15:00, 21:00 KST) 정기 스케줄러 또는 수동 실행으로 모은 증권사 리포트 본문 요약, 주요 뉴스 헤드라인, 보유종목 감성 분석, 종목 발굴 스냅샷을 회차별 묶음(batch)으로 조회한다. 묶음마다 Gemini가 작성한 종합 마켓 다이제스트가 함께 제공된다.

### 🇺🇸 미국장 시그널 룸 (`pages/3_미국장_모니터링.py`)

증권사 API로 직접 주문하지 않는 해외 직투 계좌를 위한 30분 주기 모니터링 대시보드다. 미국 주식·ETF의 일봉·30분봉 기술적 지표, 월가 컨센서스 목표가, ATR 기반 동적 손절선 및 매수 확증 캔들 필터를 실시간으로 계산하고, 조건 충족 시 화면·사운드·텔레그램으로 알림을 보낸다.

## 어떻게 판단하나

### 평시 매매와 추세 필터

`core/signal_engine.py`의 `decide()`가 종목당 사이클당 한 번 호출된다. 방향과 타이밍은 시그널이 정하고, 목표 비중 밴드는 상한 역할만 한다.

- 현재 비중이 목표+밴드+버퍼(기본 5%+5%)를 넘으면 시그널과 상관없이 밴드 경계까지 줄인다. 반대로 비중이 낮다고 억지로 사지는 않는다.
- 그 외에는 결합 시그널 강도가 0.5를 넘을 때만 매매한다. 강도에 비례해 총자산의 최대 15%까지 거래한다.
- 결합 가중치는 일봉 기술 30%, 30분봉 50%, 뉴스 감성 20%, 밸류에이션 20%다. 없는 시그널은 빼고 다시 정규화한다.
- **하락 추세 매수 차단(칼날잡기 방지)**: 일반 스윙 모드에서는 확정적 하락 추세(`SMA20 < SMA60` 및 현재가 `< SMA20`)일 때 신규 스윙 매수와 온보딩 매수를 보류한다(`REQUIRE_UPTREND_FOR_ONBOARDING`, `REQUIRE_SMA20_FOR_BUY`).
- **분할 온보딩**: 새로 편입한 종목은 중기 추세가 무너지지 않는 한 3일(`ONBOARDING_DAYS`)에 걸쳐 목표 비중까지 나눠 산다.
- **적립식(ISA/DCA) 모드**: 장기 절세 계좌 등 적립식 모드가 켜져 있으면 단기 기술적 하락 시그널에 의한 스윙 매도를 차단해 바닥 털림을 막고, 극단적 패닉셀(강도 0.85 이상)이 아닌 한 분할 적립을 이어간다.
- 모든 주문은 회당 금액(100만원)과 종목당 비중(30%) 한도로 한 번 더 잘린다.

### 손절과 추세 연동 트레일링 분할 익절 (Scale-Out)

`core/exit_guard.py`가 담당하고, 위의 평시 판단보다 먼저 평가한다.

- **손절**: 평단 대비 `-6%`(`STOP_LOSS_PCT`)면 전량 시장가 매도한다. 손절된 종목은 역추세 연속 손절을 막기 위해 5일(`STOP_LOSS_COOLDOWN_DAYS`) 동안 재진입이 금지된다.
- **트레일링 익절**: 고점이 평단보다 무장 기준(1.5×ATR%, 폴백 +3%) 이상 올랐던 포지션에만 적용한다. 고점에서 ATR 기반 폭(2.5×ATR%, 3~12% 사이, 폴백 -5%)만큼 내려오면 매도한다.
- **추세 연동 50% 분할 익절**: 중기 상승 추세(`is_uptrend=True`)에 있는 종목은 일간 노이즈에 조기 청산되지 않도록 트레일링 폭과 무장 기준을 1.5배 여유 있게 넓히고, 익절 발동 시 전량이 아니라 **50%만 분할 매도(`sell_ratio=0.5`)**하여 나머지 물량으로 추세 랠리를 끝까지 따라간다.
- 손절과 익절은 재주문 쿨다운과 일일 손실 한도를 일부러 무시한다. 다만 VI(변동성 완화장치) 중에는 보류한다.

### 30분봉

KIS 국내 분봉 API는 1분봉만 준다. 09:00 기준으로 묶어서 30분봉을 만든다. 새로 등록한 종목은 봉이 30개 쌓일 때까지 과거 데이터를 채워야 하는데, 모의투자는 초당 1건 제한이 있어서 사이클마다 3종목씩만 백필한다.

### 3계층 ETF 인텔리전스 뉴스 라우팅과 밸류에이션

네이버 금융 뉴스를 모아 새 기사만 Gemini에 보내 BUY/SELL/HOLD와 강도를 받는다. 이때 ETF는 성격에 따라 3계층(`core/news/etf_mapper.py`, `data/etf_intelligence_map.json`)으로 라우팅해 불필요한 LLM API 호출을 줄이고 정확도를 높인다.

- `SINGLE_STOCK` (단일 종목 밸류체인 ETF 등): 기초자산 주식(예: TSLA, NVDA, 삼성전자)의 뉴스 감성을 100% 상속한다.
- `THEMATIC` (섹터·테마 ETF): 상위 앵커 기업들의 뉴스 감성을 가중평균해 상속한다.
- `BROAD_INDEX` (지수·배당·채권·원자재 ETF): 개별 종목 뉴스 조회를 생략하고 기술적 지표와 매크로 컨텍스트에 집중한다.

밸류에이션은 기본으로 꺼져 있다(`ENABLE_FUNDAMENTAL_VALUATION`). 켜면 과거 PER/PBR 백분위, 네이버 컨센서스 목표가 괴리, 52주 범위 내 위치를 가중 합산한다.

### AI 포트폴리오 에이전트와 해외 프록시 대리 매매

1. 장 마감 후(16시 이후) 하루 한 번, 코스피·코스닥 전 종목 마스터와 글로벌 자산에서 후보를 모은다. 모멘텀, 증권사 리포트, 시장 뉴스 언급, 저평가(목표가 괴리), 테마 후발주 다섯 가지 소스에 매크로 자산(금·국채·달러·빅테크 ETF) 시드를 더한다.
2. **해외 프록시 매핑(`core/proxy_mapping.py`)**: 글로벌 뉴스나 리포트로 발굴된 해외 유망 종목(NVDA, GOOGL, GLD, TLT 등)은 `data/overseas_proxy_map.json`을 통해 국내 상장 대체 ETF(예: ACE 구글밸류체인액티브, KODEX 골드선물(H) 등)로 자동 변환한다. 환전·해외수수료 부담 없이 국내 계좌(특히 ISA)에서 글로벌 테마와 매크로 로테이션을 실행할 수 있다.
3. 제안을 요청하면 현재 포트폴리오, 보유 종목 퀀트 지표, 숏리스트, 시장 심리(CNN Fear & Greed) 및 매크로 로테이션 지침을 LLM에 주고 비중 조정과 편입/제외 안을 받는다.
4. `core/ai_rebalance_guard.py`가 한도를 검사한다. 총 회전율 20%, 종목당 비중 변화 10%p, 편입·제외 각 2개 등이다. 하나라도 넘으면 제안 전체를 버린다.
5. 통과한 제안은 기본값(`AI_REBALANCE_AUTO_APPLY=False`)에서는 `PROPOSED`로 저장되고 사람이 승인해야 반영된다. 대시보드나 설정에서 **Auto-Apply**를 켜면 가드레일을 통과한 제안이 즉시 목표 비중에 자율 반영된다.

### 종목을 삭제하면

바로 팔지 않는다. 신규 매수만 멈추고, 매도 신호가 나오면 전량 판다. 5일(`WINDDOWN_MAX_DAYS`)이 지나도 신호가 없으면 강제로 청산하고 포트폴리오에서 지운다. 삭제한 종목은 30일 동안 AI의 신규 편입 후보에서도 빠진다.

## 안전장치

- 모의투자 기본, 실전은 이중 확인 (`IS_MOCK`, `I_UNDERSTAND_REAL_MONEY_RISK`)
- 국내 전용 기본 (`DOMESTIC_ONLY`): 해외 종목은 직접 주문 대신 국내 상장 대체 ETF 프록시(`OVERSEAS_PROXY_TRADING_ENABLED`)로만 매매한다.
- 같은 종목 재주문은 30분 간격 (손절/익절 제외), 손절 종목은 5일간 재진입 금지 (`STOP_LOSS_COOLDOWN_DAYS`)
- 주문 체결 확인 후 보유수량 반영 및 KIS 실잔고 재조회(더블 체크) 파이프라인
- 일일 손실이 총자산의 3%에 닿으면 그날 신규 주문 중단
- 체결통보 웹소켓 하트비트 점검 및 120초 이상 무응답 시 신규 주문 중단 (동일 HTS ID 다중 계좌 구동 시 보조 계좌는 `ENABLE_WEBSOCKET=False`로 세션 충돌 방지 가능)
- 다중 프로필 KIS 토큰 만료/오류 시 자동 재발급 복구 메커니즘
- 킬스위치: 등록 종목의 35% 이상이 VI/거래정지이거나 60초 안에 주문 거부가 3번 이상이면 자동으로 발동한다. 수동으로만 해제된다.
- 프로필별 `flock` 락(`data/engine_<profile>.lock`)으로 동일 계좌 엔진이 두 개 뜨는 것을 막는다.

## 자주 보는 오류

- `EGW00133`: 토큰 발급은 1분에 한 번만 된다. 잠시 뒤 다시 시도.
- `EGW00201`: 초당 호출 제한 초과. 클라이언트가 자동으로 속도를 낮추고 재시도한다.
- `EGW02006`: 모의투자는 매도가능수량 조회를 지원하지 않는다. 보유 수량으로 대신한다.
- `IGW00002`, `40910000`: 계좌가 모의투자 주문서비스에 등록되지 않았다.
- Gemini 404 / 5xx: 5xx는 `GEMINI_FALLBACK_MODEL`이 자동으로 받아주며, 모델 단종(404) 시에는 `.env`의 `GEMINI_MODEL`을 변경한다.
- 대시보드에 "제어 플레인에 연결할 수 없습니다": 해당 프로필의 FastAPI 서버가 꺼져 있거나 포트가 다른 경우다. `uv run python scripts/manage_profile.py status` 또는 `./scripts/service.sh status`로 확인한다.
